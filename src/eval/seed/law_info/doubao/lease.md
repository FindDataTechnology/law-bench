# 租赁合同（lease）法律法规

> 来源：豆包 Doubao
> 问题：关于租赁合同的法律法规有哪些，详细的列给我

---

租赁合同全套法律法规清单（按效力层级分类，区分普通租赁、房屋租赁、融资租赁、土地租赁）
重要说明：《民法典》实施后，原《合同法》已经废止，所有租赁纠纷优先适用《民法典》；下面按法律→行政法规→部门规章→司法解释→专项规范性文件排序，并标注适用场景。
一、基础核心法律（所有租赁合同通用，最高效力）
1.《中华人民共和国民法典》
第三编 合同编・第十四章 租赁合同（第 703 条 —734 条）【普通租赁】
适用于设备、车辆、厂房、住房、场地一切一般租赁合同（区别于融资租赁）
核心规则：租赁定义、最长租期 20 年、书面形式要求、出租人与承租人权利义务、维修责任、转租、买卖不破租赁、房屋承租人优先购买权、不定期租赁、合同解除、返还租赁物等。
第三编 合同编・第十五章 融资租赁合同（第 735 条 —760 条）【融资租赁专用】
专门规范融资租赁（直租、售后回租），不适用普通房屋 / 物品租赁。
配套通用条款：
民法典总则编、物权编、合同通则（合同效力、违约责任、债权转让、保全等），所有租赁纠纷均适用。
2.《中华人民共和国城市房地产管理法》
重点条款：房屋租赁、房屋出租登记备案、划拨土地上房屋出租、房地产转让与租赁关系衔接，房屋租赁必备上位法。
3.《中华人民共和国土地管理法》《土地管理法实施条例》
规范土地使用权租赁、集体建设用地出租、国有土地租赁，土地 / 厂房租赁项目适用。
4.《中华人民共和国消防法》
租赁物业（商铺、厂房、公寓）消防合规要求；不符合消防强制性标准的房屋出租，可能导致合同无效 / 承租人有权解除合同。
二、行政法规
1.《住房租赁条例》（国务院令第 812 号，2025 年施行）
住房租赁专项行政法规
适用：城镇住宅租赁、长租公寓、住房租赁企业、二房东经营行为；
内容：禁止租金贷违规、资金监管、禁止暴力驱逐、禁止群租、房源信息管理、押金规范、出租人与承租人禁止行为。
⚠️ 仅适用于住宅住房租赁，商铺、厂房、设备租赁不适用。
三、部门规章（住建部、自然资源部等，行政监管依据）
1.《商品房屋租赁管理办法》（住建部令第 6 号）
适用：城市规划区内国有土地上商品房（住宅、商铺、写字楼）租赁
关键内容：
禁止出租房屋情形（违建、不符合安全标准、擅自改变用途等）
租赁合同必备条款、转租要求、禁止分割群租、租赁登记备案、双方安全义务。
2.《规范国有土地租赁若干意见》（自然资源部原国土部文件）
专门规范国有建设用地使用权租赁（政府作为出租人出租土地），工业用地租赁、国有土地租赁项目适用。
四、最高人民法院司法解释（法院审理案件直接裁判依据，实务最重要）
1.《最高人民法院关于审理城镇房屋租赁合同纠纷案件具体应用法律若干问题的解释》（法释〔2009〕11 号，2020 修正）
✅ 房屋租赁纠纷头号司法解释
适用范围：城市、镇规划区内城镇房屋（住宅、商铺、厂房）；福利分房、公租房、廉租房不适用；乡村房屋可参照适用。
重点解决实务难点：
违建房屋、临时建筑租赁合同效力
“一房多租” 履行顺序
装饰装修残值处理
转租合同效力、次承租人权利
房屋抵押权与租赁冲突、征收拆迁处理
2.《最高人民法院关于审理融资租赁合同纠纷案件适用法律问题的解释》（2020 修正）
仅适用于融资租赁业务，区分 “名为租赁实为借贷”、售后回租效力、租金逾期解除、租赁物取回、违约责任。
五、其他关联常用法律（租赁纠纷高频涉及）
《中华人民共和国民事诉讼法》：管辖、证据、保全、执行（腾房、租金执行）
《中华人民共和国仲裁法》：合同约定仲裁条款争议解决
《中华人民共和国个人信息保护法》：租房收集承租人身份信息合规
《中华人民共和国中小企业促进法》、《机动车登记规定》：车辆租赁、设备租赁配套规范
六、地方性法规 / 地方政府规章（各地自行制定）
各地会出台本地实施细则，举例：
《广东省城镇房屋租赁条例》《上海市房屋租赁条例》《北京市房屋租赁管理若干规定》
提示：签订租赁合同，除全国通用法规，务必查询房屋所在地省级 / 市级房屋租赁地方性规定。
七、简易适用区分指南（快速判断你要用哪套法律）
个人租房（住宅）
《民法典》租赁合同章 + 《住房租赁条例》 + 《商品房屋租赁管理办法》 + 城镇房屋租赁司法解释 + 当地住房租赁规定
商铺 / 厂房 / 写字楼租赁（商业地产）
《民法典》租赁合同章 + 城镇房屋租赁司法解释 + 《城市房地产管理法》
设备、车辆、机器普通租赁
仅适用《民法典》第七百零三条～734 条（普通租赁合同）
融资租赁（设备售后回租、直租）
《民法典》融资租赁合同章 + 融资租赁司法解释
国有土地使用权租赁（向政府租地）
《土地管理法》+《规范国有土地租赁若干意见》+《民法典》
补充重要实务提醒
租赁合同登记备案≠生效要件（《民法典》706 条），不备案不会导致合同无效，但部分城市备案影响居住证办理；
超过 20 年租期：超出部分无效，到期可续签；
区分「普通租赁」和「融资租赁」，二者法律规则完全不同，不能混用；
违法建筑出租，租赁合同原则无效，租金参照占用费处理（司法解释明确规则）。
