# 股权激励协议（equity_incentive）法律法规

> 来源：豆包 Doubao
> 问题：关于股权激励协议的法律法规有哪些，详细的列给我

---

股权激励协议适用全套法律法规清单（按效力层级 + 适用主体分类，截至 2026 年现行有效）
说明：非上市公司没有专门统一股权激励行政法规，主要适用《公司法》《民法典》及税务政策；上市公司、北交所 / 新三板挂牌公司、国企分别受专项监管规则约束；股权激励协议本质属于民事合同，同时叠加公司法、证券监管、劳动、财税多重规则。
一、基础法律（所有企业通用，股权激励协议最高效力依据）
1.《中华人民共和国民法典》
合同编：股权激励授予协议、合伙协议（持股平台）、股权转让协议效力认定、违约条款、解除权、离职回购 / 退出条款、对价、争议解决；
物权编：股权财产属性；
重点：协议是否存在无效、可撤销情形，“离职无偿收回股权”“强制低价回购” 等格式条款效力司法审查依据。
2.《中华人民共和国公司法》（2023 修订）【核心】
关键条款：
第 71 条：有限公司股权转让，公司章程可另行约定转让限制（回购、优先购买权、离职退出安排）；
第 142 条：股份公司可以回购股份用于员工持股 / 股权激励（回购资金、库存股持有期限、表决限制）；
股东优先认购权、增资程序、股东会 / 董事会决策权限；
股权登记、出资义务、代持相关规则。
3.《中华人民共和国合伙企业法》
适用场景：采用有限合伙持股平台实施股权激励
入伙、退伙、除名、财产份额转让；
协议约定 “员工身份作为合伙人资格前提”、离职强制转让份额的司法裁判基础；
有限合伙人权利、收益分配机制。
4.《中华人民共和国劳动合同法》+《劳动争议司法解释（一）》
重点边界：
股权激励≠法定劳动报酬；
区分两类纠纷：劳动关系项下股权激励授予纠纷（可能属于劳动争议）VS 纯粹股东财产权、股权转让纠纷（普通商事合同纠纷）；
不能以股权激励替代法定工资、经济补偿金；不得将股权行权作为履行劳动义务强制条件。
5.《中华人民共和国个人所得税法》及其实施条例
6.《中华人民共和国企业所得税法》及其实施条例
二、上市公司专项监管规则（A 股主板 / 创业板 / 科创板适用）
1. 《上市公司股权激励管理办法》（证监会令第 148 号，2018 修订）【上市公司核心规章】
约束：股票期权、限制性股票（第一类、第二类限制性股票）、股票增值权；
直接规范：激励对象范围、授予数量上限、行权 / 归属期限、定价、审议程序、信息披露、禁止情形、不得提供财务资助、回购注销规则，是上市公司股权激励协议必备合规底线。
2. 交易所自律规则
《上海证券交易所股票上市规则》
《深圳证券交易所股票上市规则》
《科创板上市公司持续监管办法（试行）》
《创业板上市公司持续监管办法（试行）》
上交所《科创板上市公司自律监管指南第 4 号 —— 股权激励信息披露》
深交所创业板、主板股权激励信息披露指引
重点：科创板 / 创业板允许第二类限制性股票，差异化定价规则，未盈利企业股权激励特殊要求。
三、北交所、新三板（全国股转系统 / 非上市公众公司）
《非上市公众公司监督管理办法》
《非上市公众公司监管指引第 6 号 —— 股权激励和员工持股计划的监管要求（试行）》
《全国中小企业股份转让系统股权激励和员工持股计划业务办理指南》
《北京证券交易所股票上市规则》
适用：新三板挂牌公司、北交所上市公司股权激励计划、协议条款、信息披露、决策程序。
四、国有企业股权激励专项法规（国有控股 / 国有科技企业强制适用）
国企实施股权激励，除通用法律外，必须履行国资审批，协议条款不能突破国资监管红线
《中华人民共和国企业国有资产法》
《中央企业控股上市公司实施股权激励工作指引》（国资委）
《关于进一步做好中央企业控股上市公司股权激励工作有关事项的通知》（国资发分配〔2019〕102 号）
《国有科技型企业股权和分红激励暂行办法》（财资〔2016〕4 号）—— 非上市国有科技企业
各省市国资委地方实施细则（地方国企适用）
五、财税核心规范性文件（股权激励协议涉税条款必备依据）
个人所得税
财税〔2016〕101 号《财政部 国家税务总局关于完善股权激励和技术入股有关所得税政策的通知》【最重要】
非上市公司递延纳税政策条件、备案要求；
国家税务总局公告 2016 年第 62 号：股权激励和技术入股所得税征管配套；
财税〔2005〕35 号：上市公司股票期权个税基础规则；
国税函〔2009〕461 号：限制性股票、股票增值权个税计算。
企业所得税
国家税务总局公告 2012 年第 18 号：居民企业股权激励企业所得税扣除规则
企业等待期会计上确认的费用不得税前扣除，实际行权年度允许税前扣除。
六、会计相关（方案设计、协议估值配套）
《企业会计准则第 11 号 —— 股份支付》
影响：股权激励费用摊销、等待期设定，直接影响公司利润，协议中的授予日、可行权条件、服务期条款必须匹配股份支付准则。
七、司法参考（裁判依据，用于协议风险设计）
《最高人民法院关于适用〈中华人民共和国民法典〉有关担保制度的解释》（股权质押、回购担保安排）
最高法公司类纠纷指导案例（股权代持、离职股权回购、股权激励争议裁判口径）
简易适用区分（快速对照你属于哪一类主体）
普通非上市民营企业（有限公司 / 未股改）
✅ 主要适用：《民法典》《公司法》《合伙企业法》、财税〔2016〕101 号；无强制监管审批，自治空间最大，但退出回购、代持条款风险最高。
❌ 不适用证监会《上市公司股权激励管理办法》。
A 股上市公司（主板 / 创业板 / 科创板）
✅ 全部基础法律 + 《上市公司股权激励管理办法》+ 交易所上市规则；股权激励协议条款不得违反办法强制性规定。
新三板挂牌公司 / 北交所
✅ 基础法律 + 非上市公众公司监管指引第 6 号 + 北交所 / 股转系统业务规则。
国有控股企业（上市 / 非上市）
✅ 在上述基础上叠加国资委、财政部国资激励文件，方案需要国资监管机构事前审批。
实务提示
股权激励协议常见风险条款对应的法律约束重点：
离职回购、服务期绑定：《民法典》合同效力 +《公司法》股权转让限制；
通过有限合伙平台持股：必须同时遵守《合伙协议》与股权激励授予协议，两层法律关系；
税务递延：直接影响协议中员工纳税义务、备案义务约定；
上市公司严禁向激励对象提供借款等财务资助（《上市公司股权激励管理办法》强制性条款）。
