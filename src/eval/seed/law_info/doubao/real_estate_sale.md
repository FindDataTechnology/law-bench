# 房产买卖合同（real_estate_sale）法律法规

> 来源：豆包 Doubao
> 问题：关于房产买卖合同的法律法规有哪些，详细的列给我

---

房产买卖合同全套现行法律法规清单（区分：新房 / 商品房、二手房，按效力层级排序，标注适用场景）
说明：商品房 = 开发商出售新房；存量房（二手房）= 个人之间房屋买卖；《民法典》是所有房产买卖基础；司法解释是法院裁判直接依据；行政法规、部门规章主要约束开发商、中介、行政备案。
一、法律（最高效力，全国通用）
1.《中华人民共和国民法典》【核心根本大法，新房、二手房全部适用】
重点相关编章：
物权编：第 209、215 条（区分原则：合同生效≠物权过户；未过户不影响买卖合同效力）、不动产登记、共有房屋、抵押房屋转让、善意取得、预告登记；
合同编：买卖合同通则、预约合同（认购书 / 定金协议）、定金规则、违约责任、解除权、风险转移、抗辩权；
婚姻家庭编：夫妻共同房产出售（共有权人同意问题）。
2.《中华人民共和国城市房地产管理法》【房产交易专门法律】
重点条款：房地产转让条件、商品房预售法定条件、预售合同备案、划拨土地房屋转让限制、禁止转让房屋情形。
3.《中华人民共和国土地管理法》
涉及：集体土地上房屋买卖（宅基地房屋交易限制，仅限本村集体经济组织成员）。
4.《中华人民共和国城乡规划法》
涉及：房屋规划合法性，违建房屋交易效力问题。
5.《中华人民共和国建筑法》
涉及：商品房质量、竣工验收，房屋交付法定条件。
二、行政法规（国务院颁布）
《城市房地产开发经营管理条例》
适用于开发商新建商品房；规定开发资质、竣工验收、质量保修、预售监管、交付条件。
《不动产登记暂行条例》
房屋过户、抵押权登记、预告登记、查封登记的行政程序依据。
《物业管理条例》
新房交付、配套车位、公共区域、维修基金相关交易约定。
三、部门规章（住建部等，规范开发商、中介、交易流程）
（一）商品房（新房）专用
《商品房销售管理办法》（建设部令第 88 号）
商品房现售条件、买卖合同必备条款、面积误差处理、样板房、销售广告、交付、两书（住宅质量保证书、住宅使用说明书）。
《城市商品房预售管理办法》
预售许可证要求、预售资金监管、预售合同网签备案。
（二）新房 + 二手房通用
《城市房地产转让管理规定》
房地产转让程序、应当提交材料、禁止转让房产范围。
《房地产经纪管理办法》
有中介参与买卖时适用：中介禁止行为、禁止吃差价、虚假房源、合同备案、居间义务。
（三）特殊房屋
5.《经济适用住房管理办法》、《公共租赁住房管理办法》
保障房交易限制（未满年限不得上市、补缴土地收益等）。
四、最高人民法院司法解释（法院审理房产纠纷直接裁判依据，极其重要）
1.《最高人民法院关于审理商品房买卖合同纠纷案件适用法律若干问题的解释》（2020 修正）
✅ 仅适用于：开发商销售商品房（新房），不适用于个人二手房
核心要点：预售许可证效力、广告宣传能否作为合同内容、认购定金、面积差异、逾期交房 / 逾期办证、房屋质量、贷款合同解除、惩罚性赔偿相关规则。
2.《最高人民法院关于审理买卖合同纠纷案件适用法律问题的解释》
✅ 新房、二手房全部适用
买卖合同通用规则：违约金调整、标的物检验、风险负担、价款违约等。
3.《最高人民法院关于适用〈中华人民共和国民法典〉物权编的解释（一）》
房屋共有、善意取得、不动产登记异议、预告登记纠纷。
4.《最高人民法院关于适用〈中华人民共和国民法典〉有关担保制度的解释》
抵押房屋买卖、按揭贷款、抵押权与房屋买卖冲突处理。
5.《最高人民法院关于人民法院办理执行异议和复议案件若干问题的规定》
房产被查封情形下买卖、购房者排除强制执行（刚需购房者物权期待权）。
五、地方性规范（各地自行制定，不能直接作为合同效力依据，但影响交易流程）
各省 / 市住建部门出台：
商品房预售资金监管办法
存量房（二手房）网签管理规定
本地二手房交易示范合同文本
限购、限售、税费、落户配套政策
提示：地方限购政策属于行政管理政策，一般不直接导致买卖合同无效，但会造成无法过户。
六、税收相关法律（交易税费、阴阳合同风险）
1.《中华人民共和国契税法》
2.《中华人民共和国个人所得税法》
3.《中华人民共和国增值税暂行条例》
实务重点：阴阳合同（低价网签避税）不影响买卖合同本身效力，但逃税会产生行政处罚风险。
区分：新房 VS 二手房适用法律简易对照表
表格
类型	核心专属文件	不适用文件

二手房（个人存量房）	民法典、买卖合同司法解释、房地产经纪管理办法	不适用《商品房买卖合同司法解释》
实务重要提醒
所有房屋买卖合同首要依据《民法典》；
二手房纠纷不能套用商品房司法解释，很多购房者容易混淆；
行政规章（备案、预售管理）大多属于管理性强制性规定，一般不能直接认定合同无效；
宅基地自建房买卖额外受《土地管理法》严格限制，城镇户籍购买宅基地房屋合同通常无效。
