# 知识产权许可合同（ip_license）法律法规

> 来源：豆包 Doubao
> 问题：关于知识产权许可合同的法律法规有哪些，详细的列给我

---

知识产权许可合同完整法律法规清单（现行有效，按效力层级分类）
说明：知识产权许可没有统一单行法，由《民法典》合同编通用规则 + 各知识产权单行法 + 行政法规 + 部门规章 + 最高法司法解释 + 反垄断配套规则共同构成；区分通用基础规范、分类型知识产权许可规范、备案 / 登记规则、反垄断合规、涉外相关、程序司法解释。
一、法律（最高层级）
1.《中华人民共和国民法典》（核心基础）
第三编・合同通则：合同订立、效力、履行、变更解除、违约责任、格式条款、债权债务转让（所有知识产权许可合同通用）
第八百六十二条～第八百七十七条【技术转让合同、技术许可合同专节】
直接规范：专利实施许可、技术秘密许可；同时可参照适用于集成电路布图设计、植物新品种许可。
重点条款：
技术许可合同应当书面形式
许可范围可约定，但不得限制技术竞争和技术发展
专利许可仅在专利权存续期内有效
许可人与被许可人法定权利义务、后续改进技术成果归属规则
2.《中华人民共和国专利法》（2020 修正）
第十二条：任何单位或者个人实施他人专利，应当订立实施许可合同；
第五 0～五十八条：专利开放许可、专利强制许可制度；
第十条：专利权转让规则（区分许可与转让）。
3.《中华人民共和国商标法》（2019 修正）
第四十三条：商标使用许可
许可人监督商品质量、标明被许可人名称商品产地；许可合同可备案，备案不影响合同生效，但未经备案不得对抗善意第三人。
4.《中华人民共和国著作权法》（2020 修正）
第二十六条～第三十条 著作权许可使用合同专条
明确许可合同必备条款；未明确许可的权利，被许可人不得行使；专有使用权规则。
5.《中华人民共和国反垄断法》（2022 修正）
第六十八条：依法行使知识产权不适用反垄断法；滥用知识产权排除、限制竞争，适用本法。
约束许可协议中：独占回授、禁止质疑专利效力、搭售、地域分割、限制产量、不合理限制交易对象等条款。
6.《中华人民共和国反不正当竞争法》
规范技术秘密（商业秘密）许可；保密义务、泄密违约责任；许可中保密条款合法性基础。
7.《中华人民共和国集成电路布图设计保护条例》（行政法规，下文归类）
8.《中华人民共和国植物新品种保护条例》（行政法规）
二、行政法规
《中华人民共和国专利法实施细则》（2023 修订）
第 14 条：专利实施许可合同生效之日起3 个月内可以向国知局备案（备案对抗第三人，非生效要件）。
《中华人民共和国著作权法实施条例》（2013 修订）
专有使用权定义；专有许可合同备案规则；被许可人转许可条件。
《中华人民共和国商标法实施条例》（2014 修订）
商标许可备案材料、流程；许可违规标注产地 / 被许可人名称处罚。
《集成电路布图设计保护条例》
布图设计许可使用、转让规则。
《植物新品种保护条例》
品种权实施许可、强制许可规则。
三、部门规章（行政操作、备案、强制许可）
《专利实施许可合同备案办法》（国知局令）
专利许可备案条件、材料、变更、注销；实务高频使用。
《专利实施强制许可办法》
垄断情形下、公共利益下专利强制许可规则。
《商标使用许可合同备案办法》
商标许可备案实操规范。
《禁止滥用知识产权排除、限制竞争行为规定》（市监总局 79 号令，2023 施行）
知识产权许可典型违法条款清单：拒绝许可、搭售、独占回授、限制竞争、标准必要专利 FRAND 谈判规则。
《集体商标、证明商标注册和管理办法》
集体 / 证明商标特殊许可限制。
四、最高人民法院司法解释（司法裁判核心依据，合同纠纷必看）
《最高人民法院关于审理技术合同纠纷案件适用法律若干问题的解释》（2020 修正）【重中之重】
定义：独占许可、排他许可、普通许可；
禁止性无效条款（限制竞争、无偿回授改进技术、禁止挑战专利有效性等）；
专利申请阶段许可、专利权失效后许可、许可与权属转让冲突规则；
技术秘密许可参照适用；集成电路、植物新品种许可参照适用。
《最高人民法院关于审理商标民事纠纷案件适用法律若干问题的解释》（2020 修正）
商标三类许可定义；
不同类型被许可人起诉主体资格；
许可备案对抗效力；
商标转让不影响在先有效许可合同。
《最高人民法院关于审理著作权民事纠纷案件适用法律若干问题的解释》（2020 修正）
著作权许可合同争议、专有使用权司法认定。
《最高人民法院关于审理侵犯专利权纠纷案件应用法律若干问题的解释（一）（二）》
专利许可范围内侵权认定、被许可人抗辩规则。
《最高人民法院关于审理不正当竞争民事案件应用法律若干问题的解释》
商业秘密许可、保密义务违约、泄密纠纷裁判规则。
五、反垄断配套指南（行政执法参考，协议合规审查必备）
《国务院反垄断委员会关于知识产权领域的反垄断指南》
《国务院反垄断委员会标准必要专利反垄断指南》
效力：非正式法规，但市场监管总局执法、法院审理垄断争议重要参考，起草跨国知识产权许可必须参考。
六、涉外知识产权许可相关法规（跨境 IP 授权适用）
《中华人民共和国技术进出口管理条例》
极其重要：跨境技术许可（专利、软件、技术秘密跨境授权）
禁止 / 限制进出口技术目录；
技术进口合同中不得含限制性条款（和民法典、反垄断法形成双重约束）；
技术进出口合同登记制度。
《技术进出口合同登记管理办法》
《中华人民共和国对外贸易法》
七、其他相关配套（质押、争议解决）
《专利权质押登记办法》、《著作权质权登记办法》、《商标质押登记程序规定》
许可与质押并存时权利冲突处理；
《中华人民共和国民事诉讼法》、《最高人民法院关于知识产权民事诉讼证据的若干规定》
许可合同纠纷举证、管辖。
简易使用指引（方便你落地）
国内专利 / 技术秘密许可：民法典技术许可专节 + 专利法 + 技术合同司法解释 + 反垄断规定
商标许可：商标法及实施条例 + 商标民事纠纷司法解释
软件 / 作品著作权许可：著作权法 + 实施条例 + 著作权司法解释
跨境技术许可：额外叠加《技术进出口管理条例》
协议条款合规审查：同步核对《禁止滥用知识产权排除、限制竞争行为规定》+ 技术合同司法解释无效条款清单
