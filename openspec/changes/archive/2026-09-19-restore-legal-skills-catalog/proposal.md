# Proposal: restore-legal-skills-catalog

## Why

The 85-skill curated legal-skills catalog registered on the america gateway
(mcp.token118.com, change `catalog-legal-skills-in-gateway`, 2026-08-31) was lost
with the america box retirement (2026-09-09): the gateway's Mongo skills collection
did not migrate to the replacement cheap-box gateway at
`mcp.finddatatech.cloud`, which now serves an empty catalog. The registration
automation (`scripts/infra/register_skills_gateway.py`, default gateway already
repointed) and the curation policy survive in the repo, so restoring is a re-run —
and while restoring, a fourth high-quality source repo should be folded in:
`THUYRan/Legal-Skills-Chinese` (38 lawyer-verified Chinese legal-reasoning skills,
covering 检索→推理→论证→文书), not present in the current catalog.

## What Changes

- **Restore**: re-register the existing 85-skill `CATALOG` (66 public + 19
  group-restricted) against `https://mcp.finddatatech.cloud`, riding the Logto M2M
  channel (`mcpgatewaym2m` → `registry-admins`) already proven by the law-bench MCP
  registration on the same gateway. No new auth surface.
- **Extend**: add `THUYRan/Legal-Skills-Chinese` as a fourth source repo — 38
  skills, all registered **group-restricted to `registry-admins`** because the repo
  declares CC BY-NC-ND 4.0 (non-commercial, no-derivatives): stricter than the
  existing CC-BY-NC precedent, so it follows the same group-restriction posture plus
  a serve-verbatim constraint (ND forbids modified redistribution; the gateway's
  URL-reference model already serves upstream content unmodified).
- **Slug hygiene**: THUYRan skill slugs enter the gateway's global lowercase-hyphen
  namespace; collisions with existing catalog names are resolved deterministically
  (registration aborts on an unresolved collision rather than silently overwriting).
- **Runbook migration**: new runbook `deploy/cheap-box/mcp-gateway-skills.md`
  (operating the catalog on the cheap gateway, M2M credential source there, the
  THUYRan ND policy, re-sync/drift procedure). The old
  `deploy/america-box/mcp-gateway-skills.md` stays untouched as an immutable
  historical record per AGENTS.md; a pointer note is added to the cheap-box README
  ops section.
- **Spec update**: `mcp-gateway-skills-catalog` spec requirements are rewritten for
  the new gateway host, the fourth source repo, and the NC-ND visibility rule (the
  current spec still names mcp.token118.com and a three-repo catalog).

Out of scope: modifying upstream repos; public promotion of any NC/NC-ND skill
(still requires recorded author authorization); turning skills into MCP tools or
wiring law-bench's `law_references`/`search_clauses` as data sources for the
THUYRan retrieval skills (a possible follow-up — blocked by ND on the skill-content
side, unblocked as a separate co-deployed MCP server, but not this change); the
gateway's own deployment/config (SSRF allowlist and M2M Mongo mapping already exist
from the law-bench MCP registration).

### Modified Capabilities
- `mcp-gateway-skills-catalog`: catalog host moves from mcp.token118.com (retired)
  to mcp.finddatatech.cloud; catalog grows from three source repos / 85 skills to
  four / 123 with `THUYRan/Legal-Skills-Chinese` fully group-restricted under the
  CC BY-NC-ND policy (serve-verbatim); registration automation gains a
  collision-checked registration guarantee; the operations runbook requirement
  moves to `deploy/cheap-box/`.

## Impact

- **Systems**: cheap-box AI Gateway & Registry (mcp.finddatatech.cloud, cheap1) —
  new rows in its Mongo skills collection (123 entries). No new containers, images,
  compose changes, or auth changes. Prerequisite already satisfied by the law-bench
  MCP registration: `idp_m2m_clients` Mongo mapping and `SSRF_ALLOWED_CIDRS` for the
  skill-source fetch path (github raw, public internet — unaffected by the CGNAT
  allowlist).
- **Code**: `scripts/infra/register_skills_gateway.py` — `CATALOG` gains 38 THUYRan
  entries (generated by walking the repo: frontmatter parse + license rule, same as
  the original three), plus collision detection in register. No other code touched.
- **Docs**: `deploy/cheap-box/mcp-gateway-skills.md` (new), cheap-box README ops
  pointer. `deploy/america-box/**` untouched (immutable history).
- **License risk (mitigated)**: CC BY-NC-ND served verbatim + attribution +
  group-restricted (not publicly promoted); NC precedent from the archived change is
  extended, public promotion remains authorization-gated. Upstream drift continues
  to auto-disable skills (fail-safe), making re-sync a routine runbook operation.
- **Rollback**: `remove` action per skill (or per `--repo thuyran/...`) empties the
  added entries; the gateway state is otherwise untouched.
