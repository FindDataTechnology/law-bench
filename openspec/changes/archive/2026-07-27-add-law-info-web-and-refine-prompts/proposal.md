## Why

The system seeds 41 per-contract-type drafting prompts and evaluation rubrics, but their legal citations are authored from general knowledge - they don't reference the specific governing statutes, judicial interpretations, and article ranges that apply to each type. We now have detailed, source-attributed 法律法规 surveys for all 41 types from two LLMs (Doubao + DeepSeek) under `output/law_info/`, but that directory is gitignored, not shipped to the container, and not visible anywhere in the web app. This change (a) surfaces that legal-reference data in the web, (b) uses it to produce **law-refined** prompt/rubric variants alongside the untouched baseline (so the compare feature can A/B test baseline vs law-refined), and (c) publishes a consolidated, deduplicated 法律法规 index both as a web page and a committed reference doc.

## What Changes

- Bundle the 82 law_info markdown files (41 types × {doubao, deepseek}) into the repo at `src/eval/seed/law_info/{doubao,deepseek}/<type>.md` plus `contract_types.json` - committed because `output/` is gitignored and the container has no other access to them.
- New `law_info` Postgres table (`contract_type`, `source`, `zh_name`, `content`, `created_at`) created idempotently by the same schema source of truth that creates `rubrics`/`prompts`, plus `scripts/seed_law_info.py` - an idempotent seeder that reads the bundled markdown and upserts one row per (type, source).
- New web routes: `GET /law-info` (lists all 41 types with links to both sources) and `GET /law-info/{type}` (Doubao + DeepSeek answers rendered side-by-side from markdown).
- New `GET /law-references` page aggregating every unique 法律法规 mentioned across all 82 answers, filterable by contract type and source, backed by an extracted index.
- New committed `docs/legal_references.md` - the same consolidated, deduplicated, categorized 法律法规 list as a static reference doc, generated by a script so it stays in sync with the bundled markdown.
- Seed NEW law-refined variants alongside the baseline: `draft_<type>_v2` prompts (`prompt_type = law-refined`) and `contract_<type>_v2` rubrics, with content refined using the specific statutes / interpretations / article ranges from the law_info. Baseline v1 prompts/rubrics are untouched.
- Extend `src/web/i18n.py`: nav labels for the law-info and law-references pages; add `law-refined` to the `prompt_type` data-label catalog (zh/en parity); extend the seeded-name display-title derivation so `draft_<type>_v2` and `contract_<type>_v2` render localized titles.

## Capabilities

### New Capabilities
- `law-info-web`: Browse per-contract-type 法律法规 surveys (Doubao + DeepSeek side-by-side) and an aggregated legal-references index in the web; backed by a `law_info` table seeded idempotently from bundled markdown, with a generated reference doc.

### Modified Capabilities
- `generation-prompts`: add an idempotently-seeded set of law-refined v2 variant drafting prompts (`draft_<type>_v2`, `prompt_type = law-refined`) whose content incorporates the specific governing statutes and article ranges from the law_info, alongside the untouched baseline.
- `evaluation-rules`: add an idempotently-seeded set of law-refined v2 rubrics (`contract_<type>_v2`) whose type-specific criteria reference the correct governing statutes and judicial interpretations, alongside the untouched v1 rubrics.
- `data-label-i18n`: add the `law-refined` prompt_type label (zh/en parity) and extend the seeded-name display-title derivation to handle the `_v2` suffix.
- `web-i18n`: add navigation labels for the law-info and law-references pages to the chrome catalog (zh/en parity).

## Impact

- **New files**: `src/eval/seed/law_info/{doubao,deepseek}/*.md` (82 files) + `contract_types.json`; `scripts/seed_law_info.py`; `scripts/extract_legal_references.py` (builds the aggregated index and writes `docs/legal_references.md`); `src/web/routes/law_info.py`; `src/web/templates/law_info_list.html`, `law_info_detail.html`, `law_references.html`; `docs/legal_references.md`; `tests/test_law_info.py`, `tests/test_law_info_web.py`, `tests/test_legal_references.py`.
- **Modified files**: the shared schema source of truth (`scripts/extract_harbor_rules.py` `SCHEMA` and `src/eval/store.py::ensure_schema`) to add the `law_info` table; `scripts/seed_contract_prompts.py` (append 41 `draft_<type>_v2` entries); `scripts/seed_contract_rubrics.py` (append 41 `contract_<type>_v2` entries); `src/web/app.py` (register the law_info router); `src/web/templates/base.html` (nav links); `src/web/i18n.py` (nav + prompt_type labels + title derivation); `src/eval/manage.py` or a new `src/eval/law_info.py` (read helpers); `tests/test_i18n.py` (parity test still holds with the new keys).
- **Data**: the DB grows by 82 `law_info` rows (41 types × 2 sources), 41 `draft_<type>_v2` prompt rows, and 41 `contract_<type>_v2` rubric rows. All seeding is idempotent (upsert by name / by (type, source)); baseline v1 rows are never modified.
- **Dependencies**: `markdown-it-py` is already in `uv.lock` (transitive via `rich`) - promote it to a direct dependency for server-side markdown rendering. No new external services.
- **Out of scope**: re-querying the LLMs for law_info (the bundled markdown is the source of truth); modifying the baseline v1 prompts/rubrics; RAG/vector indexing of law_info (the `/law-references` page is a direct aggregate, not a semantic search - that belongs to `rag-search`).
